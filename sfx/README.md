# Sound effects

Put **only CC0 (public domain) sound files** in this folder, because this repository is public. Do not add files from sites whose licences forbid redistributing the files (for example Pixabay or Mixkit downloads).

File names matter. The Project matches effects by file name or by a keyword in the name:
`whoosh`, `hit`, `pop`, `tick`, `chime`. Examples: `whoosh-soft.mp3`, `hit-low.wav`, `pop-ui-1.mp3`.

Formats: `.mp3`, `.wav`, `.ogg`, `.m4a`.
